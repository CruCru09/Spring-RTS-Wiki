## TextColorCode {#TextColorCode}
*class*

Indicator bytes representing color code operations during font rendering

**Fields**

- <span id="TextColorCode.Color"></span> `TextColorCode.Color` `string` — Indicates that the following bytes contain color code information
- <span id="TextColorCode.ColorAndOutline"></span> `TextColorCode.ColorAndOutline` `string` — Indicates that the following bytes contain color code and outline information
- <span id="TextColorCode.Reset"></span> `TextColorCode.Reset` `string` — Indicates reset of the current color
