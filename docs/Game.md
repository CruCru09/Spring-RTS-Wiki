# 游戏

有不少游戏是为 Spring Engine 制作的。以下是一些较受欢迎的，并按使用条款排序。

你可以通过大厅自动下载游戏。有些游戏还提供独立安装程序。

这些游戏均可免费下载和游玩，且可能允许修改，但请务必在修改前仔细阅读授权条款。

## TA-derived

这些游戏至少部分内容来源于全面歼灭游戏（版权归Wargaming所有）的数据。因此，它们的发行可能违反版权法，因此并未获得 Spring RTS 团队的官方认可。

## [平衡的歼灭](https://springrts.com/wiki/Balanced_Annihilation#Links)

![](https://dummyimage.com/300x200/eee/aaa){ width="300" height="200" align=left }

平衡歼灭（BA）是TA的粉丝模组，源自TA Demo Recorder（1999年）的开发，旨在基于原作的画面和平衡性进行扩展。BA的玩法以逐步增重的单位和不断增长的经济为基础展开。在风暴行动中，许多策略都可行，包括专注于地图控制、侵略性、防御、空中力量、海上力量或机动性。BA还举办竞技的1v1比赛，如Crown Cup 3，吸引了64名选手参加。
(网站，Discord)

## 在Spring安装游戏

上面列出的不少游戏都附带独立安装包，这让操作变得简单。去他们的网站看看吧！否则，像 SpringLobby 这样的大厅会在你加入游戏室时帮你下载所有内容。

游戏也可以手动下载为 .sdz/.sd7 文件，例如 BA750.sd7 或 XTA.sdz，并放入 ...\My Documents\My Games\Spring\Games\ 或 ...\Spring\games\ 文件夹（Linux/Unix/Mac 上为 ~/.spring/games/）。如果你的房间大厅找不到你的游戏，请阅读本页的建议。 你可以在同一个引擎安装中安装多个游戏。地图也是如此。把它们放到一个叫maps的文件夹里，和游戏文件夹同一个。
